# 🧠 MindFlow - 左右展開型 SVG マインドマップ

思考の整理やアイデア出しを妨げない、世界標準のキーボード操作（Tab/Enter）と直感的なドラッグ＆ドロップ階層再編に対応したシングルファイルWebマインドマップです。  
中心テーマから左右均等にブランチを展開するRadialレイアウトを採用し、画面スペースを広々と活用できます。

> **🚀 Live Demo:**  
> ブラウザで今すぐ使える公開版はこちら 👉 **[https://selfup.net/mindmap/](https://selfup.net/mindmap/)**

---

## 🌟 主な機能 (Features)

### 1. Radial（中央左右展開）自動レイアウト
- **バランスの良い自動配置:** 第1階層のブランチを中心ノードの左右へ均等に自動配分
- **重なりゼロの幾何計算:** 日本語の文字幅を動的に計測し、ノード同士が重ならない美しいツリー曲線を維持
- **開閉（折りたたみ）表示:** 子ノードを一時的に隠し、子ノード数バッジでコンパクトに可視化

### 2. 思考を止めない高速入力・操作体系
- `Tab`: 子ノード追加（インライン編集へ直結）
- `Enter`: 兄弟ノード追加
- `ダブルクリック` / `F2`: ノードのインラインテキスト編集
- `Delete` / `Backspace`: 選択ノード（および子孫ノード）の削除
- `Space`: 子ノードの展開・折りたたみ切り替え
- `Ctrl + Z` / `Ctrl + Y`: Undo / Redo（履歴50件）
- `マウスホイール` / `ピンチ`: スムーズな拡大・縮小
- `背景ドラッグ`: キャンバス全体のパン（移動）
- `Ctrl + 0`: ツリー全体を画面中央に収めるフィット表示

### 3. 直感的なドラッグ＆ドロップ階層再編
- ノードを掴んで別のノードへドラッグ＆ドロップするだけで、ブランチごと親子関係を付け替え（循環参照防止チェック付き）

### 4. 詳細パネル & メモ機能
- 右側のスライドパネルから、ノード名・8色のテーマカラー・長文の補足メモを編集可能
- マップ全体の総ノード数・子ノード数をリアルタイム表示
- 探したいキーワードでツリーを横断する「ノード検索機能」

### 5. はみ出し対応の全体エクスポート & バックアップ
- **全体画像書き出し (PNG / SVG):** 画面外に広がった巨大なツリーも、外枠のバウンディングボックスを自動計算して丸ごと高解像度出力
- **完全ローカル保存:** 編集内容はブラウザの `localStorage` に即座に自動保存（外部サーバー送信ゼロ）
- **JSONバックアップ & 復元:** 機種変更や保管用のデータ書き出し・読み込みに対応
